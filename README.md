## Open Source Project

### Tuvl — YAML-Driven Workflow Orchestration Engine for AI Pipelines
*Creator & maintainer · Python, FastAPI, gRPC, PostgreSQL/pgvector, Redis, React · [github.com/tuvl-io/tuvl](https://github.com/tuvl-io/tuvl) · MIT*

An engine for composing pipelines of functional nodes, LLM calls, API integrations, and MCP tools — defined in YAML and served as a REST/gRPC API. Built to take the boilerplate and vendor lock-in out of shipping multi-step AI workflows. *Currently in active development — testing and optimizing the engine across real workloads.*

- **RAG out of the box** via PostgreSQL + pgvector, with provider-agnostic LLM access through LiteLLM (OpenAI, Anthropic, Ollama, Groq, …).
- **Multi-tenant by design** — Postgres Row-Level Security for tenant isolation, plus IAM/role-based access control with cryptographic (Biscuit) token auth.
- **Built for production debugging** — per-step state snapshots, human-in-the-loop state management, structured JSON logging, and OpenTelemetry observability.
- **Tuvl Insight** — a React developer portal with a live workflow graph editor and form-driven model designer.
