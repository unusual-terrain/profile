## 🚀 Open Source Project

### **[TUVL — Deterministic Workflow Engine for AI Systems](https://tuvl.io)**
*Creator & Maintainer* • [github.com/tuvl-io/tuvl](https://github.com/tuvl-io/tuvl) • *Apache 2.0*  
*Tech Stack: Python, PostgreSQL/pgvector, Redis, OpenTelemetry, React*

* **Deterministic Execution Engine:** Architected an orchestration engine where multi-step AI workflows, API calls, and MCP tools are declared as strictly typed YAML contracts—replacing unpredictable agent looping with deterministic DAG state machines, explicit input/output schemas, and hard token/time budget boundaries.
* **Auditability & Reproducibility:** Implemented immutable per-step execution snapshots and replayable audit journals, allowing full state reconstruction, deterministic regression debugging, and human-in-the-loop pause/resume control.
* **Native RAG & Tool Ecosystem:** Built-in vector search via PostgreSQL/pgvector, provider-agnostic model routing (Claude, OpenAI, Ollama via LiteLLM), and a native **MCP Server interface** connecting IDE assistants (Claude Code, Cursor) directly to project tooling.
* **TUVL Insight Portal:** Engineered a React-based developer portal providing visual graph editing, step-level latency telemetry (OpenTelemetry), and live execution trace inspections.
